        Backup & recovery

        Download an encrypted copy of your notes and its recovery key. Save the key separately; it unlocks your personal backups.

        Whole-site recovery · Admin only
        This key unlocks the Wasabi database backup for all accounts. Wasabi access is also required.

        The whole-site recovery key has not been configured.

        Whole-site backup dashboard · Admin

        Encrypted backups cover every account. Each completed upload is downloaded and checked for recovery.

        Set up or change Wasabi storage

        Use a dedicated Wasabi backup user restricted to this folder. Keep older recovery files when changing location; old backups stay in their original location.

        Step 1 of 4 · Location

        1. Choose the backup location

        Create the bucket in the Wasabi console if needed. The wizard can create the encrypted backup folder inside it.

        2. Give the backup user permission

        In the Wasabi console, create a dedicated user with programmatic access. Create a policy using the JSON below, attach it to that user, then create its access key. If a user already has access to this folder, you can use its key.

        Creating users and changing permissions requires a Wasabi administrator. Do this in Wasabi; enter only the backup user's credentials here.

        Wasabi user and permissions guide
        3. Enter the backup credentials

        These credentials are stored privately on the server after the test succeeds. They are never included in the downloadable recovery file.

        4. Test and save

        The test creates a fresh whole-site backup, uploads it, downloads it and verifies the restored database. The existing site encryption key is retained. Saving a successful destination pauses the schedule until you enable it below.

        After setup, download the whole-site recovery file from Backup & recovery above and keep it outside this server.

        Pause prevents future scheduled runs and lets a running backup finish. Stop cancels the current run and leaves the schedule unchanged. Neither deletes stored backups.

          Help

          Write a note

          Start typing in the writing area above your notes. Your writing is saved as you go.

          Format and link

          Select text to format it or add a named link. Type / at the start of a line for a checklist, heading, quote, code block, or divider. Tap a saved checklist box to mark it done.

          Keep Favorites

          Choose the diamond in a note’s More menu to add it to Favorites. Favorites are hidden from the main view and Archive by default. To show them there too, enable Controls → Appearance → Show Favorites in main and Archive. Open Favorites from the header, then search or filter by category. Tags act as categories, and archived favorites stay in the collection.

          Find a note

          Use the search icon to search titles and content, or open Dates and options to jump to a day.

          Edit a note

          Tap or click a note to open a larger editing view. Copy highlighted text at the bottom left, or copy the whole note, including its title, when nothing is selected. Choose the green check mark to save and return to your notes.

          Note actions on a phone

          Use the quick actions beside a note or tap the three-dot button for the rest. Swipe left to open the menu and right to close it.

          Change the view

          Use the controls above your notes to change density and date sections. Unhide brings back hidden notes. Open Controls to choose quick actions, note font, and size.
